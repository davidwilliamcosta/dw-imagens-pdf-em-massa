SEO & metadados — gerar nome, title, alt e descrição para todas as imagens

Tokens: {keyword}{Keyword}{KEYWORD}{n}{n2}{n3}{total}

CSV em UTF-8 com colunas file_name, title, alt_text, description — pronto para importar no WordPress via WP All Import ou Media Library Assistant. O file_name casa com o nome do arquivo dentro do .zip.

Tamanhos responsivos — várias larguras + HTML <picture> pronto pra colar

Cada imagem sai em todas as larguras da lista que forem menores que ela, mais o tamanho original — nunca amplia. O botão </> de cada linha copia o HTML com srcset, sizes, width/height (evita o salto de layout) e o alt do SEO; o .zip leva tudo junto num picture.html. No WordPress isso não é necessário: ele gera os tamanhos sozinho.

Enviar para o WordPress — sobe direto pra biblioteca de mídia com title, alt e descrição

Use uma senha de aplicativo, não a sua senha de login: no painel do WordPress, Usuários → Perfil → Senhas de aplicativo (exige HTTPS). Os arquivos vão do seu navegador direto pro seu site, sem passar por nenhum outro servidor. Sobe a versão principal de cada imagem já convertida, com o nome, title, alt e descrição do painel de SEO; o WordPress gera os outros tamanhos.
